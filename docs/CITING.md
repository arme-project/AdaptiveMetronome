# Citing AdaptiveMetronome

If AdaptiveMetronome contributes to a publication, dataset, teaching resource,
performance analysis, or derivative software project, cite the software and the
exact version used.

## Recommended Citation Practice

Include:

- Software name: `AdaptiveMetronome`.
- Version or Git commit.
- Repository URL: <https://github.com/arme-project/AdaptiveMetronome>.
- Date accessed, if your citation style requires it.
- Any archived DOI, if a release is later deposited in Zenodo or a similar
  archive.

GitHub reads the repository's `CITATION.cff` file and can generate citation text
from the **Cite this repository** button.

For project context, cross-reference the
[ARME Adaptive Metronome demo page](https://arme-project.co.uk/demos/adaptive-metronome)
the University of Birmingham
[Virtual Reality Lab](https://virtualrealitylab.netlify.app/), and
[Massimiliano Di Luca's profile](https://massimilianodiluca.info/) where
appropriate. The University of Birmingham also has a
[news article on ARME and virtual orchestra rehearsal](https://www.birmingham.ac.uk/news/2024/dr-massimiliano-di-luca-leads-development-of-software-for-virtual-orchestra-rehearsals)
that situates the work in the VR Lab context.

The repository also includes the RPPW19 abstract PDF:
[Adaptive Metronome: A MIDI Plug-In for Modelling Cooperative Timing in Music
Ensembles](references/rppw19_abstract_Sean_Enderby.pdf).

## Example BibTeX

Replace the version, year, and access date with the exact details for the release
or commit you used.

```bibtex
@software{arme_adaptive_metronome,
  title        = {AdaptiveMetronome},
  author       = {Enderby, Sean and Stables, Ryan and Di Luca, Massimiliano},
  version      = {1.0.3},
  url          = {https://github.com/arme-project/AdaptiveMetronome},
  note         = {JUCE MIDI-effect plug-in for adaptive ensemble timing simulation},
  year         = {2026}
}
```

## Methods-Section Wording

Here is a concise wording you can adapt:

> Ensemble timing was simulated using AdaptiveMetronome, a JUCE MIDI-effect
> plug-in that loads a multi-track MIDI score and performs each note-bearing
> track as a virtual or human-operated player using a linear phase-correction
> timing model. Analyses used the CSV onset logs generated by version X.Y.Z
> of the software.

## For Maintainers

To make citations more robust, create a tagged release for each public study and
archive that release with a DOI. After creating a DOI, add it to `CITATION.cff`
and to the release notes.
