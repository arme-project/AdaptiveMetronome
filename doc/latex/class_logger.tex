\doxysubsection{Detailed Description}
Handles logging of ensemble model data. 

This class is responsible for logging the onset details of the ensemble model to a file. It runs in a separate thread to avoid blocking the audio thread, and uses an Abstract\+Fifo to manage the logging buffer.

This function starts a logging loop for the ensemble model. It first stops any existing logging loop, then initialises the logging buffer and starts a new thread to run the logging loop.
