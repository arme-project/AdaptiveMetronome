\doxysubsection{Detailed Description}
A read-\/only child class of \doxylink{class_a_r_m_e_timing_model_1_1_model_parameter_float}{Model\+Parameter\+Float} where the underlying value is the float value result of a stored std\+::function$<$float()$>$. 

This can be used when a float value has already been created elsewhere. The value cannot be changed through this parameter, and can only be used to return the value for use in the \doxylink{class_a_r_m_e_timing_model_1_1_timing_model}{Timing\+Model} calculation.

Create new parameter using the provided std\+::function$<$float()$>$ as the returned value when accessed.

{\em get\+Value\+Fcn} & This function must return a float value.\\
\hline
\end{DoxyParams}
This returns the float valued result of calling the stored std\+::function$<$float()$>$. WARNING\+: THIS DOES NOTHING. THIS VERSION OF THE PARAMETER IS CURRENTLY READ ONLY WARNING\+: THIS DOES NOTHING. THIS VERSION OF THE PARAMETER IS CURRENTLY READ ONLY

Child class of \doxylink{class_a_r_m_e_timing_model_1_1_model_parameter_float}{Model\+Parameter\+Float} that uses a normal distribution as the underlying value.

Setting the value of this parameter changes the Sigma (standard deviation) of the underlying Normal Distribution. Getting the raw value returns a random sample from Normal Distribution.
