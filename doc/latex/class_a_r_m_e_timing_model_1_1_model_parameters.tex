\doxysubsection{Detailed Description}
Base class for a structure of \doxylink{class_a_r_m_e_timing_model_1_1_model_parameters}{Model\+Parameters} used by a \doxylink{class_a_r_m_e_timing_model_1_1_timing_model}{Timing\+Model}. 

This defines a basic interface for Registering and Accessing \doxylink{class_a_r_m_e_timing_model_1_1_model_parameters}{Model\+Parameters} by Name. Initialise with the number of players (N). These parameters can be individual Model\+Float\+Parameters, Vectors of N Parameters, or Square Matrices of NxN Parameters
