\doxysubsection{Detailed Description}
Handles Polling of ensemble model data. 

This class is responsible for polling the ensemble model data at regular intervals. It runs in a separate thread to avoid blocking the audio thread, and uses an Abstract\+Fifo to manage the polling buffer.
