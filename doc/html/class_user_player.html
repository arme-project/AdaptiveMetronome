void UserPlayer::processIntroSample ( const juce::MidiBuffer & inMidi,
juce::MidiBuffer & outMidi,
int sampleIndex,
int introNote )
overridevirtual

Called from EnsembleModel to play an intro tone when a user presses a key.

This will play a note at the given introNote at the given sample index, and will stop this note after the given introToneLength samples. If any note is played by the user during this time, the intro tone will be cut off.

Parameters
inMidiThe input MIDI buffer.
outMidiThe output MIDI buffer.
sampleIndexThe current sample index.
introNoteThe note number to play for the intro tone.

Processes incoming MIDI buffer and outputs a note if the user has inputted a note, or if the user input has timed out.

If the user has not inputted a note for half an interval length, a note will be played automatically.

◆ recalculateOnsetInterval()

void UserPlayer::recalculateOnsetInterval ( int samplesPerBeat,
const std::vector< std::unique_ptr< Player > > & players )
overridevirtual

Calculates the next onset time for this user player.

This method works out when the next note should be played, based on the onsets of the other (non-user) players. If there are no other players, it simply uses the most recently played interval.

Parameters
samplesPerBeatThe number of samples in a beat.
playersA vector of all players.
