Detailed Description

Handles Polling of ensemble model data.

This class is responsible for polling the ensemble model data at regular intervals. It runs in a separate thread to avoid blocking the audio thread, and uses an AbstractFifo to manage the polling buffer.

void Poller::Start ( )

Starts the polling loop for the ensemble model.

This function stops any existing polling loop, initialises the polling buffers, and starts a new thread to run the polling loop. The polling loop will continue to run until the stopPollingLoop function is called.

void Poller::Stop ( )

Stops the polling loop by setting the continuePolling flag to false.

If the polling thread is joinable, it will join the thread to ensure proper cleanup.
