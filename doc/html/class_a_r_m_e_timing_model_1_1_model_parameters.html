Detailed Description

Base class for a structure of ModelParameters used by a TimingModel.

This defines a basic interface for Registering and Accessing ModelParameters by Name. Initialise with the number of players (N). These parameters can be individual ModelFloatParameters, Vectors of N Parameters, or Square Matrices of NxN Parameters
