void Player::processNoteOn ( const juce::MidiBuffer & inMidi,
juce::MidiBuffer & outMidi,
int sampleIndex )
protectedvirtual

Processes a single sample of incoming MIDI data for a player.

This method is called from processSample. It checks if the player should play a new note based on the onset interval and the delay (if any) set for the player. If the player should play a note, it calls playNextNote to add the note to the output MIDI buffer.

Parameters
inMidiThe incoming MIDI data.
outMidiThe output MIDI data.
sampleIndexThe sample index of the incoming MIDI data.

Reimplemented in UserPlayer.

◆ processSample()

void Player::processSample ( const juce::MidiBuffer & inMidi,
juce::MidiBuffer & outMidi,
int sampleIndex )

This method is responsible for generating the audio output for one sample of the MIDI buffer.

It checks whether the previous note has finished, and if so, plays the next note (if there is one). If not, it just decrements samplesToNextOffset to move closer to playing the next note.

Parameters
inMidiThe input MIDI buffer.
outMidiThe output MIDI buffer.
sampleIndexThe index of the sample to process in the buffers.

◆ recalculateOnsetInterval()

void Player::recalculateOnsetInterval ( int samplesPerBeat,
const std::vector< std::unique_ptr< Player > > & players )
virtual

Recalculates the next onset interval for the player.

This function updates the time keeper mean and generates noises for the current onset. It then calculates the next onset interval based on the alpha and beta parameters, the current onset time and the latest onset times of the other players.

Parameters
samplesPerBeatThe number of samples per beat.
playersThe list of other players.

Reimplemented in UserPlayer.

◆ reset()

void Player::reset ( )

Resets the player to the start of the score.

Sets the current note index to 0, resets the note on/off counters, resets the onset times, clears the note played flag, and clears the onset intervals and times vectors. Also resets the motor and timekeeper noises.

◆ setOscOnsetTime()

void Player::setOscOnsetTime ( float onsetFromOsc,
int onsetNoteNumber,
int samplesSinceFirstNote )

This method is used by the UserPlayer to set the onset time from an OSC message. It sets newOSCOnsetAvailable to true, and sets the onset time in samples. newOSCOnsetAvailable is checked in UserPlayer::processNoteOn. This should be called when a note is played from Max via OSC.

Called from EnsembleModel::setUserOnsetFromOsc.

Parameters
onsetFromOscThe onset time from the OSC message, in seconds.
onsetNoteNumberThe note number of the note that was played.
samplesSinceFirstNoteThe number of samples since the first note was played.
